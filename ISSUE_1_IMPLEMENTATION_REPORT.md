## 🏗️ Architecture Implementation

### Database Schema
```
rentalcars_carz table:
- id (PK, auto)
- car_name (CharField)

- category (CharField, choices)           [NEW]
- color (CharField)
- fuel_type (CharField, choices)
- seat_capacity (CharField, choices)
- transmission_type (CharField, choices)
- total_km_driven (PositiveIntegerField)
- bootspace (PositiveIntegerField)
- rating (DecimalField, max 5.0)         [FIXED: max_digits 2→3]
- car_image (ImageField)
- mileage (PositiveIntegerField)         [RENAMED: miliege→mileage]
- price_per_day (PositiveIntegerField)   [NEW]
- is_available (BooleanField)            [NEW]
- created_at (DateTimeField)             [NEW]
- updated_at (DateTimeField)             [NEW]
```

### API Endpoints Generated by DRF
```
GET    /api/carz/                        - List cars (paginated, filterable)
POST   /api/carz/                        - Create new car (requires authentication)
GET    /api/carz/{id}/                   - Retrieve single car details
PATCH  /api/carz/{id}/                   - Update car (requires authentication)
DELETE /api/carz/{id}/                   - Delete car (requires authentication)
POST   /api/carz/{id}/toggle_availability/ - Toggle availability status (custom action)
```

### Query Examples
```bash
# Get all Sedan cars
GET /api/carz/?category=Sedan

# Get available cars ordered by price
GET /api/carz/?is_available=true&ordering=price_per_day

# Search for Honda cars
GET /api/carz/?search=Honda

# Get cars with pagination
GET /api/carz/?limit=10&offset=20
```

## 🚀 Usage Instructions

### For Admins: Adding New Cars
1. Navigate to Django admin: `/admin/`
2. Go to Rental Cars section
3. Click "Add Car"
4. Fill in required fields:
   - car_name (e.g., "Civic")
   - company (e.g., "Honda")
   - category (e.g., "Sedan")
   - color, fuel_type, seat_capacity, transmission_type
   - total_km_driven, bootspace
   - mileage (km/l or km/kWh)
   - price_per_day (₹/day)
   - rating (0-5.0 scale)
   - car_image (optional)
   - is_available (checkbox)
5. Save - car is immediately available via API

### For Developers: Consuming the API

#### Get all cars
```bash
curl -X GET "http://localhost:8000/api/carz/"
```

#### Get available SUVs
```bash
curl -X GET "http://localhost:8000/api/carz/?category=SUV&is_available=true"
```

#### Get car details
```bash
curl -X GET "http://localhost:8000/api/carz/1/"
```

#### Create new car (requires token)
```bash
curl -X POST "http://localhost:8000/api/carz/" \
  -H "Authorization: Token YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "car_name": "City ZX",
    "company": "Honda",
    "category": "Sedan",
    "color": "Silver",
    "fuel_type": "petrol",
    "seat_capacity": "5",
    "transmission_type": "automatic",
    "total_km_driven": 0,
    "bootspace": 506,
    "mileage": 18,
    "price_per_day": 1500,
    "rating": 4.5,
    "is_available": true
  }'
```

#### Toggle availability
```bash
curl -X POST "http://localhost:8000/api/carz/1/toggle_availability/" \
  -H "Authorization: Token YOUR_TOKEN"
```
